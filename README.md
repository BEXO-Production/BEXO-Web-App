# BEXO Onboarding Flow & Core API

This is the primary BEXO Web Application, housing the central Node.js API server and the React-based Onboarding/Assessment flow for users.

## Services
- **api-server**: The core Node.js backend powering BEXO's test sessions, interviews, AI parsing, and telemetry.
- **bexo-web**: The React frontend application for student onboarding and assessments.

## Getting Started
1. Install dependencies: `pnpm install`
2. Set up your `.env` configuration (see `.env.example`).
3. Start the dev server: `pnpm run dev`
